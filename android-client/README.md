# Android Client Prototype

This folder contains the client-side integration logic used during the Guardian AI prototype.

## Responsibilities

- Receive conversation data from the messaging layer
- Preprocess messages
- Perform local AI risk analysis
- Forward analysis results to the FastAPI backend

> Note: The original Android application (Accessibility Service implementation) was developed separately during the project and is not included in this repository. This folder documents the prototype client logic used for integration with the Local Tripwire AI module.
